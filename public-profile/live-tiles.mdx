Live tiles are the **bigger cards** below your social link chips that pull live data from a platform. Each tile has a tappable **call-to-action button** (View Profile / Listen / Watch / Join). For Tarkov, Premium owners can also show a **stash** button.

## Common parts

| Part | What it shows |
|------|---------------|
| **Icon** | Platform logo. |
| **Username / handle** | Your handle on that platform. |
| **Live data** | Per-platform stats — followers, latest video, level, current rank, server status, weather, Tarkov KD, CS2 Premier, etc. (See [Live tiles editor](/connections/social-integrations) for the per-platform field list.) |
| **CTA button** | Opens your profile / playlist / video on that platform. |

## How they refresh

Tiles refresh on a **per-platform schedule** (server-side cache TTL):

- **GitHub**, **Roblox**, **Tarkov**, **Tarkov Achievements** — 6 hours.
- **YouTube**, **Spotify**, **Steam**, **X / Twitter**, **Instagram**, **TikTok** — 1 hour.
- **Valorant**, **Rainbow Six**, **CS2**, **FACEIT** — 30 minutes.
- **Twitch** — 15 minutes.
- **Minecraft server**, **Weather** — 5 minutes.
- **Discord**, **Discord server invite**, **Telegram**, **Telegram Group** — pseudo-platforms; not cached server-side. Discord presence is pushed live by the bot; invite / Telegram tiles fetch client-side.

Free **and** Premium accounts share the same per-platform TTL. On top of that, every tile is **revisited by a background cron every ~6 hours** so stale tiles eventually refresh even if no visitor opens the page.

A visitor opening your page **after** the cache expired triggers a background refresh — they see the cached data instantly; the next visitor sees fresh.

## Sections

Tiles can be split into **scroll-page sections** (`section: 1`–`10` per tile). Sections can have an optional title.
