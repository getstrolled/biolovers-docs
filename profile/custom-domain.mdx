Premium lets you put your profile on **a domain you already own**. Visitors open `https://links.yourname.com` and land on your page — no `/username` on the end.

`biolovers.site/yourname` still works. This is an extra address, not a replacement.

## What you need

- [Premium](/premium/what-premium-unlocks)
- A domain you control (any registrar)
- About five minutes for DNS to update

A **subdomain** is the easy path: `links.yourname.com`, `me.yourname.com`, `go.yourname.com`. The bare domain (`yourname.com`) works too if your DNS host supports ALIAS / ANAME / flattened CNAME — see [Apex domains](#apex-yournamecom) below.

## Steps

<Steps>
  <Step title="Open Domain & URL">
    Sign in and go to the [Domain & URL panel](https://dashboard.biolovers.site/dashboard/edit/profile/url). Under **Your own domain**, type the hostname (for example `links.yourname.com`) and click **Use this domain**.
  </Step>
  <Step title="Add the CNAME">
    The panel shows two values to copy. In your DNS host, add a **CNAME**:

    | Field | Value |
    |-------|--------|
    | **Name / host** | the hostname you typed (or just `links` if the zone is already `yourname.com`) |
    | **Target / value** | `cname.biolovers.site` |

    Leave TTL on automatic / 5 minutes if you have a choice. Do **not** add an A record for the same name.

    <AccordionGroup>
      <Accordion title="Cloudflare DNS">
        DNS → **Add record** → type **CNAME**. Name `links` (or `@` only if you are using CNAME flattening on the apex). Target `cname.biolovers.site`. Proxy status can stay **Proxied**. Save.
      </Accordion>
      <Accordion title="Namecheap">
        Domain List → **Manage** → **Advanced DNS** → **Add New Record**. Type **CNAME Record**. Host `links`. Value `cname.biolovers.site.` (the trailing dot is fine). Save.
      </Accordion>
      <Accordion title="GoDaddy">
        DNS → **Add** → **CNAME**. Name `links`. Value `cname.biolovers.site`. Save.
      </Accordion>
    </AccordionGroup>
  </Step>
  <Step title="Check DNS">
    Back on the dashboard, click **Check DNS**. If the record is not visible yet, wait a minute and click again. Most registrars update in under five minutes; a few take longer.
  </Step>
  <Step title="Wait for HTTPS">
    After DNS is found, HTTPS usually finishes on its own within a few minutes. The panel says **Live** and links your new address when it is ready. Keep the tab open — it refreshes by itself.
  </Step>
</Steps>

## Apex (`yourname.com`)

A plain CNAME is not allowed on the zone apex at many registrars. Use one of these instead of (or as well as) the CNAME:

- **Cloudflare:** CNAME on `@` with flattening (orange cloud).
- **Namecheap / others:** an **ALIAS** or **ANAME** record pointing at `cname.biolovers.site`.
- Or skip the apex and use `www.yourname.com` / `links.yourname.com`.

The dashboard also shows a **TXT** record (`_biolovers-challenge…`). Add it if Check DNS cannot see a CNAME — that proves you own the name when the registrar flattens records.

## After it is live

- Share `https://your.domain/` — that is the whole URL.
- `https://your.domain/yourname` redirects to `/`.
- Comments still post on `biolovers.site` (you have to be signed in there). Reading comments on your custom domain still works.
- Change or remove the domain any time from the same panel. The old address stops working as soon as you remove it.

## Common questions

<AccordionGroup>
  <Accordion title="Can I use strolled.dev?">
    No. That name is not offered as a profile domain anymore. Use **biolovers.site**, one of the other Premium first-party names (`larp.tax`, `dominated.lol`, `lyrisch.bio`, `vouched.lol`), or a domain you own.
  </Accordion>
  <Accordion title="Do I need to buy a new domain from Biolovers?">
    No. Use whatever you already registered. We never sell domains.
  </Accordion>
  <Accordion title="Can I connect more than one custom domain?">
    One at a time. Remove the current one first if you want to switch.
  </Accordion>
  <Accordion title="Check DNS keeps failing">
    Confirm the CNAME **target** is exactly `cname.biolovers.site` (no `https://`). Wait a few minutes. If you used the apex, add the TXT record from the panel as well. A leftover A record on the same name will block the CNAME — delete it.
  </Accordion>
  <Accordion title="The page is HTTP-only / browser warns about HTTPS">
    DNS is connected but the certificate is still issuing. Wait up to 15 minutes with the dashboard open. If it is still stuck, open a ticket in our [Discord](https://biolovers.site/discord) or use our [contact form](https://biolovers.site/contact).
  </Accordion>
</AccordionGroup>
